## ✨ Why GridBeat?

Learning music theory shouldn't feel like decoding hieroglyphics. Whether you're producing beats on a **Novation Launchpad**, laying down chords on a **piano**, or translating shapes to a **guitar or ukulele fretboard**, **GridBeat** bridges the gap.

GridBeat makes music theory intuitive, visual, and immediately playable. It turns abstract chord formulas and scale modes into clear, interactive finger patterns across all your favorite instruments at once.

---

## 🌟 Key Features

### 🎹 Multi-Instrument Real-Time Synchronization
See your chord voicings and scale patterns simultaneously mapped across:
- **Isomorphic Grid Controllers** (Launchpad, LinnStrument, Ableton Push layouts with customizable finger overlaps)
- **Piano Keyboard** (1 to 4 configurable octaves)
- **Guitar Fretboard** (3, 5, 7, 9, or 12 fret views)
- **Ukulele Fretboard** (Soprano/Concert/Tenor standard tuning)

### 🔍 Interactive Chord & Scale Explorer
- **Chord Bank:** Explore triads, 7ths, extensions, and voicings with instant root note switching.
- **Scale Explorer:** Dive into Major, Minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian, Pentatonic, Blues, and more.
- **Scale Degree Harmonic Qualities:** Automatically discover which diatonic chords naturally fit inside any scale.

### 🔊 Integrated Real-Time Audio Synthesis
- Hear every chord and scale with low-latency Web Audio powered by **Tone.js**.
- Toggle between **Synth** and **Piano** sound engines to audition progressions instantly.

### ⭐ Favorites & Voicing Library
- Bookmark and save your go-to chord progressions and voicings.
- Quick-access personal library for songwriting, practice sessions, and live performance reference.

### ⚙️ Customizable Layouts & Instrument Visibility
- Toggle individual instruments on or off to focus on your specific setup.
- Customize grid width and fret depth to match your hardware controller or acoustic instrument.

## 🛠️ Developer Quickstart

Want to run GridBeat locally or contribute to development?

### Prerequisites
- Node.js (v18.18+ or v20+)
- npm, yarn, pnpm, or bun

### 1. Clone the repository
```bash
git clone https://github.com/leouofa/gridbeat.git
cd gridbeat
```

### 2. Install dependencies
```bash
npm install
# or
yarn install
# or
pnpm install
# or
bun install
```

### 3. Run the development server
```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the app.
